# Implementation Status

The repository contains the code paths for the framework, SEF categorical depth,
temporal reprojection primitives, promptable scale prediction, physical scale
anchoring, uncertainty refinement, and failure-mode benchmark scoring.

Runtime-dependent deliverables remain intentionally unclaimed: dataset curation
counts, downloaded checkpoints, golden fixtures, trained checkpoints, benchmark
baselines, metric targets, performance measurements, CI execution, and release
publication. These require the external datasets and a powered GPU machine.
