# NYU Depth V2 SEF Experiment

## Inputs

- Dataset: NYU Depth V2 labeled archive, 1,449 aligned RGB/depth pairs.
- Split: 1,159 train / 290 validation samples, generated by
  `scripts/prepare_nyu_depth_v2.py`.
- Backbone: Depth Anything V2 Small checkpoint
  `checkpoints/depth_anything_v2_vits.pth`.
- Hardware: NVIDIA GeForce RTX 4050 Laptop GPU, 6 GB VRAM.

## Procedure

`config/sef_warmup.yaml` trained the SEF head for 20 epochs with the backbone
frozen. `config/sef_end_to_end.yaml` then loaded the warm-up head checkpoint
and fine-tuned the full model for 10 epochs. Both used 392-pixel inputs, which
are compatible with DINOv2's 14-pixel patch size.

## Result

Evaluation of `runs/sef-end-to-end/checkpoints/checkpoint_best.pth` produced:

| AbsRel | RMSE | delta1 | delta2 | delta3 |
| --- | --- | --- | --- | --- |
| 0.2884 | 1.1786 | 0.3489 | 0.6974 | 0.9037 |

The machine returned to 44 C and 0 MiB allocated GPU memory after evaluation.
These values describe the local NYU run only; they are not failure-benchmark
scores and do not freeze benchmark version `1.0.0-dev`.
