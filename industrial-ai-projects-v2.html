Depth Anything V2 — reproduce it, then publish the extension

Monocular depth foundation model from ByteDance (Lihe Yang et al., NeurIPS 2024). Fully industrial-led, official code + weights, public eval datasets. The Small (25M) and Base checkpoints run and fine-tune inside 6 GB, so you reproduce the pipeline in ~2–3 weeks and spend the rest of an 8-week window on a genuinely novel, publishable extension.

Why it is objectively strongest here
  • Highest reproducibility-per-VRAM: a real foundation model that literally fits, weights included.
  • Deterministic metrics (AbsRel, δ1) → clean, referee-friendly ablations.
  • Extension surface is wide and uncrowded (video consistency, uncertainty, metric domains).
  • High industrial impact + citations, but not "solved" — room for a main-track contribution.
Publishable extension paths
  • Temporally-consistent video depth head (V2 is per-frame → flicker is open).
  • Calibrated uncertainty for depth (paper provides none).
  • Metric-depth transfer to a novel domain (endoscopy / aerial / underwater).
  • Edge distillation Small→MobileViT for real-time on-device depth.
  • SAM 2 × depth fusion for object-level metric geometry.

Sourcing & rules applied

Hard filters. Industrial-lab authorship (from the allowed org list) · official code · public pretrained weights · public datasets · single-GPU ≤6GB feasible · 2–8 wk · clear extension surface. No survey/tutorial/blog/Kaggle/university-only/code-without-paper.
